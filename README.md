# Slipwell

Slipwell is a browser-first capture and attention system for
creator-consultants with recurring client work.

## Current repository state

The repository currently contains the interactive prototypes for
[SLIP-003](https://github.com/xuanhieu2611/Slipwell/issues/3) and
[SLIP-004](https://github.com/xuanhieu2611/Slipwell/issues/4). Together they
demonstrate Capture → Review → Today, explicit monthly-retainer rollover, and
explainable slipping signals with mock client-side state. This is not the
production application foundation and does not connect to Supabase or any AI
provider.

See the prototype guides for [SLIP-003](docs/prototypes/slip-003.md) and
[SLIP-004](docs/prototypes/slip-004.md) for scenarios, acceptance coverage,
and local commands.
