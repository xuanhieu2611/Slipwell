# Slipwell

Slipwell is a browser-first capture and attention system for
creator-consultants with recurring client work.

## Current repository state

The repository currently contains the interactive prototype for
[SLIP-003](https://github.com/xuanhieu2611/Slipwell/issues/3). It demonstrates
the Capture → Review → Today loop with mock client-side state. It is not the
production application foundation and does not connect to Supabase or any AI
provider.

See [the prototype guide](docs/prototypes/slip-003.md) for its scenario,
acceptance coverage, and local commands.
